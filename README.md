# 📕 Math2RedNote-App - 数学视频转小红书爆款神器

> 专为数学教师与教育博主打造的 AI 工具，一键提取教学视频关键帧、推导逻辑与解题口诀，快速生成高赞小红书爆款文案与 3:4 知识轮播卡片。

## 🌟 核心功能
- 🎥 **本地视频关键帧抓取**：浏览器本地解析，快速捕获黑板板书与推导重点。
- 🤖 **Gemini 2.5 爆款排版算法**：自动提炼痛点首句、极简步骤拆解、考场秒杀口诀与热门标签。
- 📱 **3:4 小红书卡片实时模拟**：支持在线修改图片文字、公式与步骤。
- 🖼️ **高清批量导出**：一键生成 1080x1440 适合小红书算法的高清图文卡片。
- 🚀 **GitHub 一键发布与部署**：开箱即用支持 GitHub Pages 在线运行。

## 🛠️ 本地运行与部署
```bash
# 1. 克隆仓库
git clone https://github.com/YOUR_USERNAME/Math2RedNote-App.git
cd Math2RedNote-App

# 2. 安装依赖并启动
npm install
npm run dev
```
